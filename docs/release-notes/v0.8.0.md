# MMD Canvas v0.8.0

Manage shaders as standalone `.shader` asset containers and separate shader authoring from per-material assignment.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).**

## Changes

- **`.shader` data containers**: shaders are stored on disk as `.shader` files (JSON containers with metadata — name, outline, description, author, tags — plus the assembled function-stack layers). `src/core/shader-file.js` validates them with a strict allowlist and writes atomically. Property defaults live in the layer code (`//@property`); per-material values live in the workspace.
- **Workspace stores references, not code**: `.canvas` keeps `materialInstances[].ref` (`builtin:<name>` or a relative `.shader` path) + per-material params, and a `shaderFiles` registry. References relativize against the canvas directory like model/texture paths (`mapPaths`), so a `shaders/` folder beside the model is managed and restored by relative path. Legacy embedded-shader migration was removed; old canvases fall back to built-ins.
- **Authoring / assignment separation**: the shader-stack editor (Ctrl+Shift+K) is now a pure shader authoring/management tool — no material selector or assignment UI. It edits built-in + user shaders as function stacks, previews the **selected shader** on the sphere, and saves/exports `.shader` files. Per-material shader **assignment** and **independent property values** are edited in the **material inspector** ("셰이더" section), Unity-style.
- **Built-ins as assembled stacks**: built-in shaders are themselves stacks of separable functions, not monolithic code. Default Toon = **ToonBand** (2-band direct light) + **ToonFill** (flat ambient fill); Standard = empty (neutral Lambert base).
- **Built-in save policy**: built-ins are in-memory read-only templates. Editing one marks it dirty (●); saving exports a new `.shader` at a user-chosen path (the built-in baseline is preserved). Closing the project with unsaved modifications shows a save prompt.
- **Inspector applies immediately**: inspector assignment/property edits sync the viewport mirror directly from the IPC result and re-render, so changes apply without depending on push-broadcast delivery. Slider drags are preserved (rebuild skipped while a property control has focus).
- **Library discovery**: user `.shader` files in the `shaders/` directory beside the canvas/model are discovered into the library; runtime keeps stackId-based PSO selection while persistence uses stable refs.

## Validation and limitations

Local validation uses an RTX 4090. Core tests (47, including `.shader` format round-trip/allowlist and relative-path ref relativization), the shader editor + per-material inspector UI test, the material-panel UI test, and the DX12/DLSS/presentation/lifetime GPU regressions passed. Workspace save/restore passed in ko/en/zh/ja/de. Packaging verified 528 runtime files and all 56 Example files.

`materialCount*STRIDE ≤ 4096` still bounds the parameter buffer; library max-slot changes recompile all stacks. Built-in modifications are transient until exported to a `.shader` file. This remains a native DX12 path only; Three.js `ShaderMaterial` is unsupported. GPUs other than RTX 4090 have not been locally validated. [Implementation and limitations](https://github.com/mazelines/MMD-Canvas/blob/v0.8.0/docs/shader-stack.md).

The installer includes all 56 Example files and opens the bundled canvas on first launch. The installer is unsigned; `SHA256SUMS.txt` contains its checksum. In-app automatic updates are not available.

## 한국어

- 셰이더를 **`.shader` 데이터 컨테이너**(메타데이터 + Function Stack 레이어) 파일로 관리합니다. `.canvas`는 셰이더 코드 대신 **상대경로 참조**(`materialInstances[].ref` + `shaderFiles`)만 저장하며, 모델 하위 `shaders/` 폴더를 상대경로로 관리·복원합니다. 레거시 임베드 마이그레이션은 제거했습니다.
- **저작/지정 분리**: 셰이더 스택 편집기는 순수 셰이더 저작/관리 도구(머티리얼 선택 없음, 선택 셰이더 구체 프리뷰, `.shader` 저장/내보내기). 머티리얼별 셰이더 지정과 독립 프로퍼티 값 편집은 머티리얼 인스펙터에서 합니다.
- **빌트인 조립 구조**: Default Toon = ToonBand + ToonFill, Standard = 빈 스택(중립 Lambert). 빌트인은 메모리 템플릿이며 수정 시 더티(●) → 저장 시 유저 지정 경로에 새 `.shader`로 내보냅니다. 프로젝트 종료 시 미저장 수정본은 저장 알림 대화상자로 안내합니다.
- 인스펙터 지정/프로퍼티 수정은 IPC 반환 상태로 뷰포트를 직접 갱신해 즉시 적용됩니다(푸시 브로드캐스트 의존 제거). 슬라이더 드래그는 보존됩니다.
- `shaders/` 디렉토리 디스커버리로 사용자 `.shader`를 라이브러리에 로드합니다. 런타임은 stackId 기반 PSO 선택을 유지하고 영속화만 안정적 ref를 사용합니다.
- 검증: 코어 47개(`.shader` 포맷·상대경로 ref 포함), 셰이더 편집기+인스펙터 UI, 머티리얼 패널 UI, DX12/DLSS/presentation/lifetime GPU 회귀, 워크스페이스 5개 로케일, 패키징 528 런타임 + 56 Example 통과.
