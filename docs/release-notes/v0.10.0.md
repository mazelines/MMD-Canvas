# MMD Canvas v0.10.0

Reusable shader functions and explicit top-to-bottom execution in the shader stack editor.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU.**

## Shader stacking improvements

- **Separate shader and function assets:** `.shader` stores ordered function references and enabled states; `.shaderStack` stores a reusable HLSL function, its property defaults, and metadata. The editor supports opening, saving, and saving a copy of individual functions. Shared function edits update every loaded shader that references the same file.
- **Visible execution order:** numbered functions run from top to bottom. Drag to reorder, insert with the `+` between rows, or append through Add/Open Function. Disabled functions show `—` and are skipped.
- **Stable material instances:** reordering and reusing functions preserve layer IDs and independent per-material property values. Repeated uses of a function compile in separate namespaces, including helper functions.
- **Reliable editing and preview:** failed compilation keeps the last working shader active. Changes to function defaults and parameter layouts reach the preview immediately. Missing function files produce a visible error instead of silently dropping the shader.
- **Demo:** all four README languages include a clickable YouTube preview of the [shader stacking video](https://youtu.be/1XLbQnIKI9s).

## Compatibility and validation

Existing v1 `.shader` files still open. Saving writes the v2 reference format and extracts inline functions into `.shaderStack` files while preserving layer IDs. Keep the shader and its referenced function files together when moving a project. Earlier app versions cannot read v2 shaders.

Validation includes 54 core tests and real DX12 tests for shader compilation, function save/open/reuse, per-material properties, execution order, drag reordering, disabled functions, and save/reload. Packaging checks the runtime files, bundled Example, DX12 bytecode, and required native libraries.

The Windows installer is unsigned. `SHA256SUMS.txt` contains the installer checksum. The app notifies you about new releases; installation is manual.

## 한국어

- **셰이더 스태킹 고도화:** `.shader`는 함수 조합과 실행 순서를, `.shaderStack`은 개별 HLSL 함수 코드와 프로퍼티 기본값을 저장합니다. 함수 불러오기·저장·다른 이름 저장과 여러 셰이더 간 재사용을 지원합니다.
- 함수 목록은 **맨 위가 첫 실행, 맨 아래가 마지막 실행**입니다. 실행 번호와 방향을 표시하고, 드래그 재정렬·경계 삽입·맨 아래 추가·비활성 함수 건너뛰기를 지원합니다.
- 함수 재사용과 재정렬 후에도 머티리얼별 프로퍼티 값을 유지합니다. 컴파일 오류가 나면 마지막으로 정상 적용된 셰이더를 유지하며, 누락된 함수 파일은 오류로 안내합니다.
- 한국어·영어·중국어·일본어 README에 시연 영상과 미리보기 이미지를 추가했습니다. [함수 추가·저장·재사용 방법](https://github.com/mazelines/MMD-Canvas/blob/v0.10.0/docs/shader-stack.md).
- 기존 v1 파일을 열 수 있으며, 저장하면 v2와 개별 함수 파일로 분리합니다. **v2 파일은 이전 앱에서 열 수 없습니다.** 프로젝트를 옮길 때 참조된 함수 파일도 함께 이동하세요.
