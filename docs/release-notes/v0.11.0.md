# MMD Canvas v0.11.0

Shader function library: object-space vertical gradients and masked self-emission.

## New functions

- **VerticalTwoColorBlending** blends top and bottom colors using the whole model's object-space local Y height. At 50% top-color coverage it is a uniform linear gradient; 0% and 100% produce solid bottom and top colors. The gradient follows translation, rotation, and nonuniform scale, with shared reference bounds across submeshes. Blend strength controls how much of the preceding stack result is replaced.
- **SelfEmission** adds light-independent surface emission with a separate mask texture, intensity in nits, and a color-source toggle: diffuse color or a selected emission color. Masks use linear red-channel data and the mesh's original UVs, independently of the diffuse map. PNG, JPEG, BMP, and WebP are supported. An unassigned mask emits everywhere; an unreadable file blocks emission and reports its path.

Both functions are available under **Shader editor → Add function**, provided as `.shaderStack` assets. Inserted functions are editable copies saved into the project, so projects do not depend on paths inside the installed app. Material-specific masks and values persist in `.canvas`; mask references are saved as relative paths. Move the referenced images with the project.

Functions execute from top to bottom. Place SelfEmission below VerticalTwoColorBlending to add emission to the gradient. Emission changes surface brightness; it does not add bloom or illuminate surrounding objects.

Custom HLSL functions can now declare `texture2D` properties and sample them with `sampleShaderTexture(mask, ctx.rawUV)`. The shared context also exposes normalized model-local `ctx.objectHeight`.

## 한국어

- **VerticalTwoColorBlending**: 모델 전체의 오브젝트 스페이스 로컬 Y 높이를 기준으로 위·아래 색상을 보간합니다. 상단 색 점유율 50%는 선형 그라디언트, 0%/100%는 하단/상단 단색입니다. 모델의 이동·회전·비균일 스케일에도 따라갑니다.
- **SelfEmission**: 별도 발광 마스크, 발광 강도(nit), 발광 색상을 제공합니다. 토글을 켜면 자체발광 + 디퓨즈 컬러, 끄면 자체발광 + 지정 발광 컬러입니다. 마스크는 R 채널을 사용하며, 미지정은 전체 발광, 읽기 실패는 발광 차단으로 처리합니다.
- 두 함수는 함수 추가 메뉴에서 선택하고 `.shaderStack`으로 저장·재사용할 수 있습니다. 머티리얼별 마스크와 값은 `.canvas` 저장·재열기에서 복원됩니다. 그라디언트 아래에 SelfEmission을 배치하면 그 결과에 발광을 더합니다.
- 한국어·영어·일본어·중국어 README와 함수 사용 설명을 업데이트했습니다.

## Validation

Core tests cover asset schemas, independent material mask bindings, workspace path round-trips, and model-local bounds under transforms. Local DX12 GPU/UI checks cover linear interpolation and coverage endpoints, transformed gradients, both emission color modes, mask orientation, missing/cleared masks, diffuse-map independence, texture picking, and saved function assets. Existing shader-stack and DLAA/DLSS regressions also pass. Release CI builds and verifies the Windows x64 installer, bundled runtime, and Example files.
