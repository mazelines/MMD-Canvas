# MMD Canvas v0.8.2

Automatic release notifications and corrected directional depth rims.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).**

## Changes

- Check GitHub for a newer stable version at startup and every six hours. A dismissible banner opens the official release page for manual download and installation. Dismissal persists per version; offline, timeout and rate-limit failures stay silent.
- Add a dismissible first-launch GitHub star suggestion and a star button on the welcome screen. Notifications stack without overlapping.
- Correct DepthRimLight after comparison with JTRP. Signed relative depth and smoothstep exclude foreground occluders; background is treated explicitly as open space. Out-of-screen samples are rejected. Sun-directed sampling is retained as a separate variation of JTRP's normal-directed method.
- Replace cubic width with a linear screen-space width: one width unit is 3 pixels at 1080p, proportional to viewport height and independent of model units or camera distance. Previously authored `.shader` files are not rewritten.
- Unify all 23 bundled example material rim settings: width 3, bias 0, fade 0.26, intensity 0.39, white color. Keep per-material toon parameters and relative shader references.
- Korean, English, Simplified Chinese and Japanese notification text and README updates.

## 한국어

- 앱 시작 시와 실행 중 6시간마다 새 정식 버전을 확인합니다. 다운로드 알림은 공식 릴리스 페이지를 열며 설치는 사용자가 직접 진행합니다. 닫은 버전은 다시 알리지 않고 네트워크 오류는 작업을 방해하지 않습니다.
- 첫 실행의 GitHub 별 주기 안내와 빈 화면의 별 주기 버튼을 추가했습니다. 업데이트 알림과 겹치지 않게 배치했습니다.
- DepthRimLight를 JTRP 원본과 대조해 수정했습니다. 부호 있는 상대 깊이 차와 smoothstep으로 앞쪽 가림막을 제외하고, 배경은 열린 공간으로 처리하며 화면 밖 샘플은 버립니다. JTRP의 법선 방향 방식과 구분되는 태양 방향 변형입니다.
- 림 폭을 세제곱에서 선형 계산으로 변경했습니다. 1080p 기준 폭 1은 3픽셀이며 해상도에 비례합니다. 기존 사용자 `.shader` 파일은 자동 수정하지 않습니다.
- 번들 예제 23개 머티리얼의 림 설정을 폭 3, 임계값 0, 전이 폭 0.26, 강도 0.39, 흰색으로 통일했습니다. 개별 툰 설정과 상대경로 참조는 유지합니다.
- 한국어·영어·중국어 간체·일본어 알림 문구와 README를 갱신했습니다.
