# MMD Canvas v0.5.2

**Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+) are required.** This release uses native DX12 for all 3D rendering. WebGL rendering has been removed; macOS and Linux packages are no longer provided.

## Changes

- Fix GPU presentation stalls and shared-texture pool exhaustion. Copy each DX12 frame to presentation-owned GPU storage, wait for copy completion, and return the external frame. Limit retained source frames to three and handle delayed consumers, GPU recovery, and renderer reloads.
- Add hardware DXR soft shadows with adjustable light size and 16/64/128 rays.
- Add CORTAO 1.0.3 to Lambert and Toon indirect lighting before exposure and tone mapping, with filtered/raw debug views. Material AO combines with screen AO using `min(materialAO, screenAO)`; direct light and emission are preserved.
- Render posed/morphed meshes, native Toon outlines, and supported DDS textures through DX12. Add playback controls for models that contain animation clips; VMD loading is not supported.
- Include every file under `Example`, including nested textures and the `.canvas` workspace. Restore the user's previous workspace when valid; otherwise open the bundled `Zhuang Fangyi.canvas`.
- Validate packaged runtime files, native shaders/LUT, and all 56 example files against their sources.

The bundled legacy workspace has no AO settings and opens with CORTAO disabled. Enable CORTAO to evaluate its contribution. [Pipeline, equations, and current limitations](https://github.com/mazelines/MMD-Canvas/blob/v0.5.2/docs/native-dx12.md).

## Validation

- 36 core tests; material/animation UI, workspace startup/restore, and native DXR/CORTAO/color checks.
- 1,200 frames of the real example with moving camera and three window sizes: no GPU-process exits, 1,201 imported frames returned, zero outstanding frames at completion (RTX 4090).
- Delayed-consumer backpressure, repeated failed imports, bounded recovery, and real GPU-process restart followed by continued rendering.
- Shipping executable startup and bundled example display checked locally. The release workflow separately compiles and packages the tagged source.

The installer is unsigned. In-app automatic updates are not available; close the running app and install the new version. `SHA256SUMS.txt` contains the installer checksum.
