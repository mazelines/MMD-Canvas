# MMD Canvas v0.5.3

Fix DXR shadow acne in Lambert and Toon while preserving shadows from nearby thin geometry.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).**

## Changes

- Separate the geometric normal used to launch shadow rays from the normal-map/bump-map shading normal. Read the actual posed triangle for each material draw.
- Project the rasterized position onto the triangle plane and apply an offset based on coordinate and triangle size, with outward float rounding. Use a separate centroid position for MSAA edges without changing material interpolation.
- Remove the global model-size bias and use `TMin = 0` after offsetting the origin, preserving nearby intersections. Keep rays on the visible geometric side and retain alpha-mask checks and real self-occlusion from adjacent triangles.
- Add GPU regression coverage and document the calculation and limitations. [Implementation details](https://github.com/mazelines/MMD-Canvas/blob/v0.5.3/docs/native-dx12.md#dxr-자기-교차-방지).

## Validation

- The original isolated-plane reproduction darkened all 6,400 inspected pixels. After the fix, the shadow on/off difference is zero in ten Lambert/Toon cases spanning scales of 0.001–1,000, distant positive/negative coordinates, and front/back faces.
- Multiple material draws, transparent rendering, indexed/non-indexed geometry, and pose updates pass. A thin blocker with a 0.00005-unit gap retains its shadow when unrelated model bounds grow.
- Existing DXR penumbra, alpha-mask, CORTAO, exposure, emission, DDS, resize, and GPU presentation checks pass on the local GPU.
- The real bundled example completed 1,200 camera/resize frames with zero GPU-process exits; all 1,201 imported frames were returned. Maximum observed frame time was 28.9 ms in that run.

The raster-path offset uses a conservative error estimate; it is not a universal guarantee for every GPU or extreme geometry. Shading-normal shadow terminator artifacts are a separate issue. The release workflow builds and verifies the tagged source and includes all 56 files under `Example`.

The installer is unsigned. Close the running app and install the new version; in-app automatic updates are not available. `SHA256SUMS.txt` contains the installer checksum.
