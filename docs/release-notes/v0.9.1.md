# MMD Canvas v0.9.1

Per-mesh viewport selection outline: selecting an individual mesh outlines only that mesh, not the whole loaded object.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).**

## Changes

- **Per-mesh selection granularity**: viewport selection changes from whole-object to individual mesh. Clicking a mesh — or selecting its material row in the inspector — draws the light-orange (`#ff9a3d`) outer-silhouette ring around that mesh only. The selection/ID mask already stores a per-material identifier (`nativeId+1`), so `outputMain` now rings the region whose mask equals the selected id (`sharpening.y` = selected `nativeId+1`, 0 = none) instead of the whole coverage. The ring is drawn against the background and against neighbouring meshes, so a mesh buried inside the model is still outlined along its visible silhouette.
- **Unified selection and edit target**: the clicked/selected mesh is both the outline target and the inspector edit target. Inspector row clicks drive the same selection (`onSelect`). Empty-space click / Esc / model reload clear the selection.
- **Unchanged**: GPU-mask picking accuracy (alpha holes, hidden nodes, visible translucent surfaces), gesture latching, frame/mapping generation binding, and post-AA ring stability (constant symmetric width, no flicker or ghosting) are preserved. Non-selected frames are identical to v0.9.0 — the outline block runs only when a mesh is selected.

## Validation and limitations

Local validation uses an RTX 4090. `tests/viewport-selection.cjs` (`npm run test:selection`) now asserts per-mesh granularity (selecting mesh B rings only B: zero orange pixels on the unselected half) and inspector-driven selection via `onSelect`, in addition to the existing picking / gesture / AA-stability / IPC-delay cases. Core 50 tests and the DX12/DLSS rendering regressions pass; CI pack verifies the runtime tree, the bundled Example, and the DX12 shader bytecode.

Selection is per mesh (material) on the native DX12 path only. Picking reads the last rendered mask, so a click before the first frame of a newly uploaded model reads as empty. [Implementation](https://github.com/mazelines/MMD-Canvas/blob/v0.9.1/docs/native-dx12.md).

The installer includes all 57 Example files and opens the bundled canvas on first launch. The installer is unsigned; `SHA256SUMS.txt` contains its checksum. In-app automatic updates are not available.

## 한국어

- 뷰포트 선택을 오브젝트 전체 → 개별 메시 단위로 세분화. 메시 클릭(또는 인스펙터 머티리얼 행 선택) 시 해당 메시 둘레에만 오렌지 바깥쪽 실루엣 링. 마스크가 머티리얼별 식별자(nativeId+1)를 이미 기록하므로 outputMain이 선택 ID 영역에 인접한 링만 합성(배경·인접 메시 경계 모두). 모델 내부에 묻힌 메시도 보이는 실루엣을 따라 아웃라인.
- 선택이자 편집 대상 통합: 클릭/선택 메시가 아웃라인 대상이자 인스펙터 편집 대상. 인스펙터 행 클릭도 같은 선택을 구동(onSelect). 빈 곳/Esc/재로드 시 해제.
- 유지: GPU 마스크 픽킹 정확도(알파 구멍·숨김 노드·반투명), 제스처 latch, 프레임/매핑 세대 정합, post-AA 링 안정성(일정·대칭 폭, 깜빡임/잔상 없음). 미선택 프레임은 v0.9.0과 동일(링 블록은 선택 시에만 실행).
- 검증: test:selection에 메시별 입도(선택 메시 B만 링)·인스펙터 구동 검증 추가, 기존 픽킹/제스처/AA 안정성/IPC 지연 케이스 유지. 코어 50, DX12/DLSS 렌더링 회귀 통과. CI pack이 런타임·번들 Example·DX12 bytecode 검증.
