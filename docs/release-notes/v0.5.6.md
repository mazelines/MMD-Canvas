# MMD Canvas v0.5.6

Improve viewport grid stability, add NVIDIA NIS sharpening, and make transparent materials easier to identify.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).** DLAA and DLSS availability still depends on the NVIDIA RTX GPU and driver; unsupported GPUs use DX12 MSAA 4×.

## Changes

- Fix broken, uneven and flickering grid lines at shallow camera angles. Evaluate the projected ground footprint per line direction at output resolution, keeping ordinary lines near one pixel and center axes near 1.5 pixels. Fade dense distant lines and antialias the boundary. The grid is composed after reconstruction, independently of DLSS resolution and jitter.
- Disable the grid by default, including the bundled first-launch canvas. Existing user projects retain their saved grid setting.
- Show transparent materials with yellow checkboxes in the material list. The indication updates after texture alpha detection and material changes.
- Add NVIDIA Image Scaling SDK v1.0.3 NVSharpen, pinned to commit `35e13ba316c98eeecf16f37eae70ce88019911f6`. Use only its adaptive directional sharpening pass; DLSS continues to handle reconstruction and upscaling.
- Add a locally saved 0–100% sharpening control, defaulting to 25%. Apply it after tone mapping, background/grid composition and sRGB conversion in DLAA, DLSS Quality/Balanced and MSAA. At 0%, skip the pass entirely; AO debug bypasses it. Strength changes preserve reconstruction history.
- Include the NIS MIT license and verify its shader in packaged builds. Continue bundling every Example file, the signed DLSS runtime and its separate license.

## Validation and limitations

Local validation uses an RTX 4090. Grid regressions cover three camera angles, small camera movements, all four AA modes, static output, the visibility toggle and the horizon. The unsharpened grid produces identical pixels across the AA modes. GPU tests also cover reconstruction, sharpening strength, flat background preservation, debug bypass, MSAA fallback, CORTAO and DXR composition.

All 36 core tests, material UI tests and the 1,200-frame camera/resize/AA-switch stability test passed. All 1,232 imported frames were returned, with no GPU-process exits. DX12 debug validation reported no errors. Local packaging verified 522 runtime files and all 56 Example files; a fresh profile opened the bundled canvas with DLAA and sharpening at 25%.

Sharpening can amplify residual temporal fluctuation around fine geometry or transparent edges. Reduce the strength or set it to 0% when this is distracting. The experimental DLSS alpha-reconstruction limitations from v0.5.5 remain. GPUs other than RTX 4090 have not been locally validated. [Implementation and limitations](https://github.com/mazelines/MMD-Canvas/blob/v0.5.6/docs/dlss.md).

The installer includes all 56 Example files and opens the bundled canvas on first launch. The installer is unsigned; `SHA256SUMS.txt` contains its checksum. In-app automatic updates are not available.

## 한국어

- 비스듬한 시점에서 그리드 선이 끊기거나 깜빡이는 문제를 수정하고, 먼 거리의 선과 외곽을 부드럽게 처리했습니다.
- 그리드 기본값을 꺼짐으로 변경하고 첫 실행의 번들 캔버스에도 반영했습니다. 기존 사용자 프로젝트의 저장값은 유지합니다.
- 반투명 재질은 머티리얼 목록의 체크박스를 노란색으로 표시하며, 텍스처 알파 판정 후에도 갱신됩니다.
- NVIDIA NIS NVSharpen을 추가했습니다. DLAA·DLSS·MSAA에서 0–100%로 조절하며 기본값은 25%입니다. 0%에서는 패스를 건너뛰고, AO 디버그에는 적용하지 않습니다.
- 샤픈은 미세한 시간 변동을 강조할 수 있습니다. 필요하면 강도를 낮추거나 0%로 끄십시오.
- Windows 11 x64 설치 파일에 Example 전체, NVIDIA 런타임·라이선스와 NIS 라이선스를 포함합니다.
