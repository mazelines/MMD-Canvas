# MMD Canvas v0.5.4

Reduce close-up rendering cost with low-ray DXR shadows reconstructed using motion vectors, temporal accumulation, and spatial denoising.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).**

## Changes

- Replace the default 64-ray inline shadow calculation with a separate 4-ray visibility pass. Offer 1-ray realtime, 2-ray balanced, 4-ray high quality, and an unfiltered 128-ray reference mode.
- Reproject shadows using the previous rendered camera and posed vertices, including skinning and morphs. Reject mismatched surfaces, clamp stale visibility, and reset history after light, projection, model, or viewport changes.
- Accumulate up to 32 frames in a static view, with a shorter history during pose updates. Finish convergence after interaction stops, then stop requesting redraws.
- Apply two spatial filter passes guided by geometric normals, surface positions, variance, and estimated penumbra size. Preserve the v0.5.3 geometric-normal origin correction and thin contact shadows.
- Apply reconstructed visibility inside Lambert/Toon direct lighting before EV100 and GT7. CORTAO remains a separate indirect-light calculation. Hard shadows use one ray without temporal blur.
- Add reproducible GPU quality tests and `npm run test:zoom` for the bundled example. Update all four README languages and the native renderer documentation.

## Validation

- On an RTX 4090 at 1280×900, a close-up of the bundled example measured about 9.8 ms with the previous 64-ray path and 1.9 ms with 4 rays plus reconstruction. These are local median native rendering times, including command recording and GPU completion waits; they exclude model upload and presentation and are not a universal FPS guarantee.
- Compare 1/2/4-ray static convergence, camera movement, and moved occluders against 128-ray reference renders. Check disocclusion, light/resize resets, exposure independence, and direct-light preservation with AO.
- The existing Lambert/Toon self-intersection regressions also pass through the temporal path, covering extreme scales/coordinates, front/back faces, pose updates, transparency, and thin blockers.
- The real example completed 1,200 camera/resize frames with zero GPU-process exits. All 1,232 imported frames were returned, including startup accumulation.
- Core tests, native/shader compilation, package content checks, and packaged first launch pass locally. The release workflow builds and verifies the tagged source and includes all 56 files under `Example`.

This is a custom native DX12 temporal/spatial shadow filter. It does not integrate NVIDIA NRD, DLSS, or DLAA; scene antialiasing still uses 4× MSAA. Secondary transparent layers and MSAA fragments that do not match the single-surface prepass use low-ray inline evaluation and can retain fine noise.

[Implementation and limitations](https://github.com/mazelines/MMD-Canvas/blob/v0.5.4/docs/native-dx12.md#모션-벡터와-시간-누적-그림자).

The installer is unsigned. Close the running app and install the new version; in-app automatic updates are not available. `SHA256SUMS.txt` contains the installer checksum.

## 한국어

- 기본 DXR 그림자를 64광선에서 4광선+모션 벡터·시간 누적·공간 디노이징으로 변경했습니다. 1·2·4광선과 비교용 128광선 모드를 제공합니다.
- 카메라·스키닝·모프 움직임을 반영하고, 조명 변경·가림 해제 시 이전 그림자가 남지 않도록 누적을 검사합니다. 정지 시 최대 32프레임을 누적한 뒤 추가 렌더링을 멈춥니다.
- RTX 4090·1280×900 근접 화면에서 네이티브 렌더링이 약 9.8ms에서 1.9ms로 줄었습니다. 화면 전송을 포함한 전체 FPS와는 다른 수치입니다.
- GPU 품질·자기 교차 회귀 테스트와 실제 예제 1,200프레임 안정성 검증을 통과했습니다. 투명 레이어와 일부 MSAA 경계에는 미세한 노이즈가 남을 수 있습니다.
- 이번 버전의 안티앨리어싱은 4× MSAA입니다. DLAA·DLSS는 포함하지 않습니다. `Example` 전체 파일을 포함합니다.
