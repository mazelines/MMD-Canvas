# MMD Canvas v0.8.1

Fix the bundled Example workspace so its shader references are portable relative paths.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).**

## Changes

- **Bundled Example shader references fixed**: the Example `Zhuang Fangyi.canvas` had stored absolute `.shader` references pointing at a development-machine path, and the referenced `.shader` file was not bundled. On a fresh install the shader could not be resolved and fell back to the built-in. The example now bundles `Example/Zhuang Fangyi/shaders/Default_Toon.shader` (an assembled Default Toon stack with DepthRimLight + ToonBand + ToonFill) and all `materialInstances[].ref` / `shaderFiles` entries use the relative path `shaders/Default_Toon.shader`, resolved against the canvas directory like model/texture paths.
- First launch opens the bundled Example canvas and loads its shader correctly on any machine.

## Validation and limitations

Local validation uses an RTX 4090. Verified the Example canvas decodes with relative refs resolving to the bundled `.shader` (loads: DepthRimLight + ToonBand + ToonFill, outline enabled). Packaging verified 528 runtime files and all 57 Example files (now including the bundled `.shader`).

The installer includes all 57 Example files and opens the bundled canvas on first launch. The installer is unsigned; `SHA256SUMS.txt` contains its checksum. In-app automatic updates are not available.
