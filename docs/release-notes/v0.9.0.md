# MMD Canvas v0.9.0

Unreal/Blender-style viewport object selection with a stable screen-space selection outline.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).**

## Changes

- **Object selection + screen-space outline**: clicking the viewport selects the whole loaded object and draws a light-orange (`#ff9a3d`) outer-silhouette ring, computed in `outputMain` after temporal reconstruction from a non-jittered selection mask. Separate from the toon hull outline (works on planes/open surfaces), stable across AA phases (no flicker on a static view), no ghosting on select/deselect. Ring width is constant and symmetric across MSAA/DLAA/DLSS (output-pixel dilation with preserved fractional phase).
- **GPU-mask picking**: a native selection/ID mask (R32_UINT, dedicated non-jittered depth + color pass) is read back at the click pixel (opcode 10). Alpha policy matches the color pass (`max(alphaTest,0.001)`), so alpha-0 holes pick the surface behind, hidden nodes are excluded, and visible translucent surfaces are pickable. Global material identity mapping gives correct panel indices for multi-mesh scenes.
- **Frame/mapping generation binding**: a published `pickState` (native generation + panelIndices snapshot) is refreshed only when the model/mapping changes; ordinary frame advancement keeps it so in-flight clicks are not cancelled. Rebuild start invalidates pending picks; stale/invalid responses return null (not treated as empty-space deselect). Esc/clear/reload invalidate in-flight picks.
- **Gesture latching**: camera drag, gizmo manipulation, return-to-start drag, and pointercancel/lost capture do not select; empty click / Esc deselect. The clicked material syncs to the inspector edit target (separate from object selection).
- **Performance**: mask pass draws depth once + ID once (removed duplicate geometry submission).
- **Packaging**: `maskVertex.cso` / `maskMain.cso` / `maskDepthMain.cso` added to the required native shader verification.

## Validation and limitations

Local validation uses an RTX 4090. `tests/viewport-selection.cjs` (`npm run test:selection`) covers object selection, second-material inspector sync, Esc/empty clear, global index / alpha hole / translucent / hidden node, gizmo/drag/cancel, plane/sphere outline, ring XOR stability = 0 and symmetric 2px width across AA modes, and three IPC-delay timings (unchanged-frame keeps the click; rebuild before/after frame invalidates the stale response). Core 50 tests and DX12/DLSS/shader-ui/presentation/lifetime regressions pass; pack verifies 529 runtime + 57 Example files + DX12 bytecode. An independent code review (5 rounds) verified the selection regressions and real-flush IPC-delay scenarios.

Selection is object-level; the inspector edit target is the clicked material. Picking reads the last rendered mask, so a click before the first frame of a newly uploaded model reads as empty. Native DX12 path only. [Implementation](https://github.com/mazelines/MMD-Canvas/blob/v0.9.0/docs/native-dx12.md).

The installer includes all 57 Example files and opens the bundled canvas on first launch. The installer is unsigned; `SHA256SUMS.txt` contains its checksum. In-app automatic updates are not available.

## 한국어

- 언리얼/블렌더 스타일 뷰포트 오브젝트 선택: 클릭 시 로드된 오브젝트 전체 선택 + 화면공간 오렌지 바깥쪽 실루엣 링. 카툰 외곽선과 분리, 평면/열린 표면 표시, AA 위상 무관 안정, 선택/해제 잔상 없음, 전 AA 모드 일정·대칭 링 폭.
- GPU 마스크 픽킹: 알파/alphaTest/계층 가시성이 화면과 일치(알파 구멍 뒤 면·숨김 노드·반투명 처리), 전역 머티리얼 매핑.
- 프레임/매핑 세대 정합: 일반 프레임 진행은 대기 중 클릭을 취소하지 않음, rebuild 시 무효화, stale 응답은 null(빈 공간 해제와 구분). Esc/clear/reload 무효화.
- 제스처 latch: 카메라/기즈모/되돌아오는 드래그/cancel 비선택, 빈 곳/Esc 해제. 클릭 머티리얼은 인스펙터 편집 대상으로 별도 동기화.
- 마스크 패스 중복 draw 제거(깊이 1회+ID 1회). 마스크 셰이더 3종 패키지 필수 검증 추가.
- 검증: test:selection(3개 IPC 지연 타이밍 포함), 코어 50, DX12/DLSS/shader-ui/presentation/lifetime, pack 529+57+bytecode. 독립 5차 코드 리뷰 통과.
