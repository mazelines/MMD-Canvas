# MMD Canvas v0.6.1

Add a depth-based rim light example (DepthRimLight) and screen-space depth sampling for shader stack layers.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).**

## Changes

- **DepthRimLight example layer**: inspired by the depth-based rim light technique used in miHoYo-style subculture games (Genshin / Star Rail / MooaToon). Instead of a fresnel (`N·V`) term, it samples neighbor scene depth along the projected light direction and brightens the silhouette where depth breaks. Offset `lightDirScreen/depth × (3·width)·width²`; mask `saturate((|Δz|/depth − bias)/fade)`. Uses a relative depth difference to suit the prepass background=0 depth convention, so the rim lands on the light-facing silhouette.
- **Screen-space depth sampling infrastructure**: `ShadingContext` gains `viewportSize` and `lightDirScreen` (sun direction projected to screen XY, y flipped), and a `sampleSceneDepth(pixel)` helper reads the prepass depth (`normalDepth`, t4; view-space depth, 0 = background). Stack layers can now build depth-based rim/edge effects.
- Properties: rim width, depth threshold (bias), fade, intensity, rim color — auto-generated sliders/picker.

## Validation and limitations

Local validation uses an RTX 4090. All 40 core tests and the editor UI test passed. The shader-stack backend test now also applies DepthRimLight and verifies it compiles (the `sampleSceneDepth` helper resolves) and visibly changes the silhouette. The packaged editor preview and main character viewport both render the depth rim (compiled once, fanned out to both hosts). Packaging verified 528 runtime files and all 56 Example files.

The technique references community frame-analysis/reproduction write-ups, not official miHoYo engine specs; the Genshin/Star Rail/JTRP/MooaToon variants differ in offset direction and threshold, and this example uses the light-direction (MooaToon) style. Material default values from the games are not published and are not claimed. GPUs other than RTX 4090 have not been locally validated. [Implementation and limitations](https://github.com/mazelines/MMD-Canvas/blob/v0.6.1/docs/shader-stack.md).

The installer includes all 56 Example files and opens the bundled canvas on first launch. The installer is unsigned; `SHA256SUMS.txt` contains its checksum. In-app automatic updates are not available.
