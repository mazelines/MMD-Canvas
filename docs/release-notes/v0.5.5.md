# MMD Canvas v0.5.5

Add native NVIDIA DLAA as the default antialiasing mode, with DLSS Quality and Balanced performance options for Lambert and Toon rendering.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).** DLAA and DLSS Super Resolution support NVIDIA RTX 20-series and newer, subject to the installed driver and NGX capability check. Unsupported GPUs use the existing DX12 4× MSAA path.

## Changes

- Add DLAA, DLSS Quality, DLSS Balanced and MSAA 4× to the viewport. Remember the selection locally and show the actual active mode beside the native rendering time.
- Integrate NVIDIA NGX D3D12 directly using DLSS SDK v310.9.16 and Transformer Preset K. There is no native swapchain or Streamline present hook.
- Reconstruct HDR color and alpha before EV100 and GT7, with depth, unjittered current-to-previous motion vectors, camera jitter and exposure. Motion includes the previously rendered skinned/morphed pose and Toon hull outlines.
- Use SDK-recommended internal resolutions. At 1280×900 output, Quality renders at 853×600 and Balanced at 742×522; DLAA renders at native resolution.
- Preserve display background colors and the grid at output resolution. Keep CORTAO on indirect lighting and DXR shadows on direct lighting. Update their projection/reprojection for jitter.
- Reset AA history on mode, viewport, model/material, lighting/exposure and large camera changes. Finish up to 32 static frames, then stop redraws. AO debug and wireframe use MSAA.
- Include the signed NVIDIA distribution DLL and its separate SDK license. Pin the download to an immutable commit with SHA-256 verification, and verify the packaged DLL, shaders and all 56 Example files.

## Validation and limitations

On RTX 4090, core tests and GPU regressions passed for mode selection, resolutions, camera/pose movement, disocclusion, resets, background/exposure preservation, Lambert/Toon CORTAO and DXR composition. The example completed 1,200 camera/resize/AA-switch frames with zero GPU-process exits and all 1,232 imported frames returned. DX12 debug validation reported no errors; existing buffer initial-state warnings remain. Missing-DLL testing confirmed MSAA fallback. The packaged app opens the bundled `Zhuang Fangyi.canvas` automatically with DLAA.

Alpha reconstruction uses NVIDIA's experimental `AlphaUpscaling` feature. Very thin geometry and transparent boundaries may retain shimmer or ghosting, especially in Balanced. Overlapping transparent layers have only one motion/depth guide per pixel. DLSS has its own processing cost and is not necessarily faster at low resolutions or in light scenes. GPU generations other than RTX 4090 have not been locally validated.

This release adds DLAA and Super Resolution, **not DLSS 5 Neural Rendering, Frame Generation or Ray Reconstruction**. [Implementation, SDK terms and limitations](https://github.com/mazelines/MMD-Canvas/blob/v0.5.5/docs/dlss.md).

The installer is unsigned. Close the running app before installing. In-app automatic updates are not available; `SHA256SUMS.txt` contains the installer checksum. NVIDIA RTX™ DLSS / NVIDIA NGX SDK are provided under their own included license, separate from the project's MIT license.

- HDR 색상·투명도·깊이·모션 벡터로 EV100·GT7 이전에 복원합니다. Lambert·Toon, 스키닝·모프, 헐 윤곽선과 카메라 움직임을 반영합니다.

- 아주 가는 형상과 투명 경계에는 특히 Balanced에서 흔들림이 남을 수 있습니다. SDK의 알파 복원은 실험적 기능입니다.
