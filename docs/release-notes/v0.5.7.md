# MMD Canvas v0.5.7

Add a code-based shader stack editor that lets users extend a loaded PMX character's surface shading with their own HLSL functions.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).** DLAA and DLSS availability still depends on the NVIDIA RTX GPU and driver; unsupported GPUs use DX12 MSAA 4×.

## Changes

- Add a **Shader Stack** inspector tab. Users author `void fn(inout ShadingContext ctx)` HLSL layers and stack them in order on top of the fixed built-in character lighting (Lambert/Toon, DXR shadows, CORTAO, emission). It is a code editor, not a node graph.
- Introduce a shared `ShadingContext` (surface, material, lighting intermediates and result). `colorMain` is refactored into a fixed `baseShading` plus a `runUserStack` injection point; with an empty stack the result is bit-identical to v0.5.6.
- Declare layer parameters with `//@property <type> <name> = <default> [min,max] "label"` annotations (float/float2/float3/float4/int/bool/color). The editor auto-generates sliders, color pickers and checkboxes from the active stack, and parameter changes upload without recompiling.
- Compile user stacks at runtime with a bundled DirectX Shader Compiler and hot-swap the native color PSOs (vertex stage and non-color passes unchanged). An empty stack restores the build-time default shader. Compiler errors are reported in the editor and never kill the renderer.
- Ship RimLight, Fresnel, ColorGrade and ToonRamp example layers, a CodeMirror 5 code editor, and stack reorder/enable/remove controls. Persist the stack (code, order, enabled state, parameters) in the workspace `.canvas` under a strict allowlist validator.
- Bundle DXC (`dxc.exe`, `dxcompiler.dll`, `dxil.dll`, Windows SDK redistributables) and CodeMirror (MIT) with license notices, and verify them in packaged builds. Continue bundling every Example file, the signed DLSS runtime, NIS and their separate licenses.

## Validation and limitations

Local validation uses an RTX 4090. All 40 core tests (including new shader-stack parser tests), the material UI tests, the DX12 and DLSS/sharpening GPU regressions, and the 1,200-frame camera/resize/AA-switch stability test passed; the base-shading refactor leaves the reconstruction reference errors unchanged. New GPU tests cover runtime compile → hot-swap → pixel change, parameter modulation without recompile, bit-identical default restore, and compiler-error survival. A real-DOM UI test covers the tab, layer add, code editor, auto-generated properties and persistence round-trip. Local packaging verified 525 runtime files and all 56 Example files, including the bundled DXC and HLSL sources.

Runtime compilation can take a few seconds and runs asynchronously with a status indicator. A user shader that hangs the GPU is bounded by the existing 10-second fence timeout, after which the host recovers. This is a native DX12 path only; Three.js `ShaderMaterial` remains unsupported. DXC is redistributed under the Windows SDK license and CodeMirror under MIT. GPUs other than RTX 4090 have not been locally validated. [Implementation, syntax and limitations](https://github.com/mazelines/MMD-Canvas/blob/v0.5.7/docs/shader-stack.md).

The installer includes all 56 Example files and opens the bundled canvas on first launch. The installer is unsigned; `SHA256SUMS.txt` contains its checksum. In-app automatic updates are not available.

## 한국어

- 인스펙터에 **셰이더 스택** 탭을 추가했습니다. 사용자가 작성한 `void fn(inout ShadingContext ctx)` HLSL 함수를 순서대로 쌓아 PMX 캐릭터의 표면 셰이딩을 확장합니다. 노드 그래프가 아닌 코드 편집 기반입니다.
- 내장 라이팅은 고정 베이스로 유지하며, 스택이 비어 있으면 v0.5.6과 비트 동일한 결과를 냅니다.
- `//@property` 주석으로 선언한 파라미터는 스택에 따라 슬라이더·컬러픽커·체크박스로 자동 생성되고, 값 변경은 재컴파일 없이 반영됩니다.
- 사용자 스택은 동봉 DXC로 런타임 컴파일되어 네이티브 color PSO를 핫스왑합니다. 컴파일 오류는 에디터에 표시되며 렌더러를 종료시키지 않습니다.
- RimLight·Fresnel·ColorGrade·ToonRamp 예제, CodeMirror 5 에디터, 스택 재정렬·활성·제거, 워크스페이스 저장·복원을 제공합니다.
- DXC(Windows SDK 재배포)와 CodeMirror(MIT)를 라이선스 고지와 함께 설치 파일에 포함하고 패키징에서 검증합니다.
- 런타임 컴파일은 수 초 걸릴 수 있으며 비동기로 처리합니다. GPU를 멈추는 셰이더는 기존 10초 펜스 타임아웃으로 제한되고 호스트가 복구합니다. 네이티브 DX12 전용 경로이며 Three.js ShaderMaterial은 지원하지 않습니다.
