# MMD Canvas v0.6.0

Redesign the shader stack editor as an Unreal-material-editor-style working canvas with a live material preview.

**Requires Windows 11 x64 and a DirectX 12 Ultimate GPU (feature level 12_2, DXR 1.1+).**

## Changes

- **Working canvas layout**: the editor window now has a material preview in the center canvas and the stack layer panel on the right, with the code editor below the preview and properties below the stack.
- **Material preview**: a neutral material sphere renders in the center with an orbit camera (drag to rotate, wheel to zoom). Applying a stack updates the sphere immediately. The preview is rendered by a **second independent DX12 host** (its own native child process) presenting to the editor window; the main character viewport keeps its own host.
- **Drag-and-drop reorder**: stack layers reorder by dragging, with a drop indicator.
- **Insert between layers**: a **+** icon at each layer boundary opens a function-catalog popup; selecting an entry inserts it at that position. Inserted function names are made unique so the generated HLSL never redefines a function.
- **Delete**: select a layer and press **Del/Backspace**, or **right-click → Delete**.
- **Sender-routed IPC**: main dispatches `dx12:*` calls and presentation acks by window sender, so the editor's viewport drives the preview host while the main window drives the main host. The shader stack compiles once and fans out to both hosts.
- Fix the editor menu accelerator (Ctrl+Shift+K now opens the window) and a CodeMirror stale-layer edit bug.

## Validation and limitations

Local validation uses an RTX 4090. All 40 core tests, the DX12/DLSS/sharpening/presentation/lifetime GPU regressions, and the shader-stack backend test passed. A real-DOM UI test verifies the preview renders, the + popup inserts, drag reorder, context-menu and Del deletion, auto-properties, the main-viewport effect, restore, and persistence. The packaged editor window's preview was verified to render (asar importmap and second-host paths resolve). Packaging verified 528 runtime files and all 56 Example files.

The preview adds a second D3D12 device/PSO/target pool (roughly double native GPU memory while the editor is open); the preview uses MSAA and a controlled output size to limit cost, and its child process is stopped when the editor closes. Two hosts' frame ids are disambiguated by sender. This remains a native DX12 path only; Three.js `ShaderMaterial` is unsupported. GPUs other than RTX 4090 have not been locally validated. [Implementation and limitations](https://github.com/mazelines/MMD-Canvas/blob/v0.6.0/docs/shader-stack.md).

The installer includes all 56 Example files and opens the bundled canvas on first launch. The installer is unsigned; `SHA256SUMS.txt` contains its checksum. In-app automatic updates are not available.

## 한국어

- 셰이더 스택 편집기를 언리얼 머티리얼 에디터 스타일의 작업 캔버스로 재설계했습니다. 가운데 머티리얼 프리뷰, 우측 스택 레이어, 하단 코드 에디터/프로퍼티 구성입니다.
- 머티리얼 구체 프리뷰를 오빗 카메라(드래그 회전·휠 줌)로 관찰하며, 스택 적용 시 즉시 반영됩니다. 프리뷰는 독립된 두 번째 DX12 호스트(별도 네이티브 프로세스)가 렌더링합니다.
- 스택 레이어를 드래그앤드롭으로 재정렬하고, 경계의 + 팝업으로 함수를 사이에 삽입하며, Del/Backspace 또는 우클릭 메뉴로 삭제합니다. 삽입 함수 이름은 중복되지 않게 자동 부여됩니다.
- main이 sender 기반으로 IPC/ack를 라우팅하고, 셰이더 스택은 컴파일 1회로 양 호스트에 fan-out됩니다.
- 편집기 메뉴 단축키(Ctrl+Shift+K)와 CodeMirror stale-layer 편집 버그를 수정했습니다.
- 프리뷰는 편집 창이 열려 있는 동안 네이티브 GPU 메모리를 약 2배 사용합니다(MSAA·출력 크기 제어로 완화, 창 닫으면 자식 프로세스 정리). 네이티브 DX12 전용 경로이며 Three.js ShaderMaterial은 지원하지 않습니다.
